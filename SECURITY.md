# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |
| < 0.1.0 | ❌        |

## Reporting a vulnerability

Please report security issues privately through GitHub Private Vulnerability Reporting:
**https://github.com/ladown/formle/security/advisories/new**

**Do not open a public issue for security reports.** Public disclosure before a fix is available puts users at risk.

## Response expectations

Formle is a personal open-source project, so triage is best-effort. You can expect an initial acknowledgement within a few days. Coordinated disclosure timing will be agreed on a case-by-case basis once a fix is in progress.
